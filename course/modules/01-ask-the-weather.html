Ask About the Weather

What this little agent does, and the journey a single question takes before it comes back as an answer.

What is this thing?

You type "Wat is het weer in Amsterdam op 2026-09-21? Geef kledingadvies." and get back a friendly Dutch answer: rain is likely, bring an umbrella, wear a light jacket. That is the whole product.

Under the hood it is a starter kit for building an agent with the Claude Agent SDK. It is deliberately tiny so you can see every moving part.

🌦️

One tool

get_weather looks up temperature and chance of rain for a city and date.

☂️

One decision rule

Rain chance of 60% or more means "bring umbrella". Everything else: leave it.

🧥

One mini-quest

Add clothing advice (jas / geen jas / paraplu) by editing instructions only, no new code.

Two ways to run it

The kit has a free practice lane and a real lane. Think of a pilot: the flight simulator needs no fuel, the real plane needs a ticket (your API key).

1
Simulator lane (always runs)

Uses a built-in fixture: Amsterdam, 14°C, 72% rain. No internet, no AI, no cost.

2
Live lane (only with a key)

If ANTHROPIC_API_KEY is set as an environment variable, Claude itself gets the question and calls the tool.
