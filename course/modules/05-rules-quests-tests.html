Rules, Quests and Tests

The plain-code rules that back up Claude, the "edit instructions, not code" quest, and the tests that keep everyone honest.

A thermostat with two dials

A thermostat doesn't think. Below the set point it heats; above it, it doesn't. decide.ts is two of those dials: one for temperature (coat or not), one for rain (umbrella or not).

src/decide.ts 
export const clothingAdvice = (weather: WeatherObservation): string => {
  const parts: string[] = [];
  if (weather.temperatureC < 12) parts.push('jas aan');
  else if (weather.temperatureC < 18) parts.push('lichte jas of trui');
  else parts.push('geen jas nodig');
  parts.push(decideWeather(weather) === 'bring umbrella' ? 'paraplu mee' : 'geen paraplu');
  return parts.join('; ');
};
PLAIN ENGLISH

A function that takes one weather reading and returns a sentence of advice.

Start with an empty list of advice pieces (an array).

Colder than 12°C? Add "jas aan" (wear a coat).

Otherwise, colder than 18°C? Add "lichte jas of trui" (light jacket or sweater).

Otherwise add "geen jas nodig" (no coat needed).

Reuse the umbrella rule (60%+ rain): add "paraplu mee" or "geen paraplu".

Glue the pieces together with a semicolon: "lichte jas of trui; paraplu mee".

Done.

💡
Same rule, two places

The 60% rule is written in code (decideWeather) and in English (instructions.md). Code gives a guaranteed answer; the prompt only asks Claude nicely. Keep both in sync, or the fixture lane and the live lane will disagree.

The quest: change the briefing, not the car

To make a sat-nav speak Dutch you change a setting, you don't rebuild the engine. The clothing quest works the same way: the README says do not add a new tool. You edit instructions.md, and a checker script confirms you did.

src/quest-clothing.ts 
if (!/kleding|clothing|jas|paraplu/i.test(instructions)) {
  console.error('Mini-quest incomplete: add clothing advice to instructions.md');
  process.exit(1);
}
PLAIN ENGLISH

Search the instructions text for any of these words: kleding, clothing, jas, paraplu (upper or lower case). This search pattern is a regex. If none are found...

...print a clear message saying what is missing...

...and quit with exit code 1, meaning "failed".

(Otherwise carry on and print the fixture advice.)

Tests: the smoke-alarm button

You press the test button on a smoke alarm without setting the house on fire. Unit tests do the same: known weather in, expected advice out, no API key, no network.

tests/weather-tool.test.ts 
test('fixture weather tool works without API key or network', async () => {
  const weather = await fetchWeather({ city: 'Amsterdam', date: '2026-09-21', useFixture: true });
  assert.equal(weather.precipitationProbability, FIXTURE_WEATHER.precipitationProbability);
  assert.equal(decideWeather(weather), 'bring umbrella');
});
PLAIN ENGLISH

A test with a name that says what it proves.

Ask the tool for Amsterdam weather, fixture mode on.

Assert the rain chance is exactly the fixture's 72.

Assert 72% rain leads to "bring umbrella".

End of test.
